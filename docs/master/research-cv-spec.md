# Research CV Specification

## Purpose

The PI-outreach CV should be **research-oriented and concise (target: 1-2 pages)**.

Do not use a generic software-engineering resume.

The document should make the following story legible within the first half page:

> Mechatronics / systems -> physiological sensing -> medical imaging -> genomics -> scientific software -> Master's research in computational biological systems.

## Recommended order

### 1. Header

- Name
- current role / organisation
- email
- GitHub
- Google Scholar / ORCID / publication profile if available
- location optional

### 2. Research identity - 2 lines maximum

Suggested content:

> Mechatronics-trained R&D engineer working across physiological sensing, medical imaging, genomics and scientific software. Interested in rigorous computational methods and systems for heterogeneous biological evidence.

### 3. Research / professional experience

Order by research relevance, not by generic corporate chronology.

#### GeneStory - R&D

Foreground:

- genomics / sequencing-data research;
- public research outputs;
- scientific-software / pipeline work;
- validation / evidence handling;
- scale or dataset size only when exact and defensible.

#### DNA - open-source scientific software

Treat this as a research-engineering project, not a hobby.

Foreground:

- scientific correctness;
- evidence-preserving architecture;
- sequence/signal processing;
- reproducible pipelines;
- validation / testing;
- open-source ownership.

#### Earable Neuroscience

Foreground:

- physiological / neural sensing;
- wearable measurements;
- raw-signal processing;
- algorithms / embedded or systems work;
- real-world R&D constraints.

#### VinBigData

Keep concise.

Foreground:

- medical-imaging exposure;
- ML / image data;
- what methodological insight was gained.

### 4. Education

- BEng / Honors Program in Mechatronics Engineering
- UET-VNU
- GPA 3.47 / 4.0 - Distinction
- thesis title
- thesis grade A+
- only the most relevant courses

### 5. Publications / research outputs

Use exact citations when available.

Separate:

- peer-reviewed / public papers;
- preprints / reports if appropriate;
- research award.

Do not inflate publication status.

### 6. Selected awards

Include only high-signal items:

- undergraduate scientific research award;
- two semester scholarships;
- Second Prize - Data For Life.

### 7. Technical methods

Group by research function rather than an exhaustive technology list.

Examples:

- **Scientific computing:** Python, Rust, reproducible pipelines, testing
- **Biological data:** sequencing / variant evidence / genomic pipelines
- **Signals & sensing:** physiological signals, measurement, signal processing
- **Modelling:** statistics, ML, optimization / control foundations
- **Software systems:** open-source architecture, data pipelines, validation
