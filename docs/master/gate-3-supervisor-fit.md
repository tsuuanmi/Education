# Gate 3 - Supervisor and Lab Fit

This pass evaluates the seven core research programmes at PI/lab level.

The purpose is not to predict whether a professor will accept the applicant. It asks a narrower and more useful question:

> Is there a concrete research group where the applicant's existing evidence can support a credible Master's research proposal?

## Evaluation lens

A strong PI match should ideally connect several of these at once:

1. EEG / neural or physiological sensing;
2. signal processing, estimation, control or embedded systems;
3. Mechatronics / instrumentation / device building;
4. research software and reproducible scientific engineering;
5. optional genomics / biomedical-data continuity.

A programme with several strong PIs is safer than one with a single perfect lab because supervisor capacity can change.

**Third: Yoonkey Nam**

**Conclusion:** deepest direct neurotechnology cluster in the current portfolio.

## Outreach policy

Do not ask a generic "Are you accepting students?" as the entire email.

A useful first contact should establish:

1. one specific current research direction from the lab;
2. one concrete link to the applicant's existing work;
3. one plausible research question or method the applicant could contribute;
4. a concise ask about whether the direction is suitable for a 2027 Master's research application.

The core narrative should change by lab:

- **neural decoding labs**: EEG -> robust/adaptive decoding -> closed-loop interface;
- **wearable hardware labs**: Mechatronics + Earable -> low-power multimodal physiological sensing;
- **control labs**: control/estimation -> physiological state estimation / closed-loop intervention;
- **biosensor/diagnostic labs**: sensors + GeneStory -> measurement systems connecting physical and molecular evidence;
- **imaging labs**: instrumentation + AI/software -> acquisition-to-inference biomedical systems.
