# Expanded Opportunity Universe - Draft

## Status

This is a **working draft**, not yet the canonical replacement for `opportunities.csv`.

It combines:

- the old 78-record universe;
- 87 genuinely new/replacement Discovery-2.0 routes;
- no extra rows for the 8 merge/reframe records.

Total draft size: **165 application-distinct records**.

## Gate-1 state across the combined draft

- Likely: 107
- Conditional-high-risk: 42
- Unlikely: 10
- Superseded: 4
- Not-actionable: 2

These counts mix:
- the already-closed old Gate 1; and
- the still-being-audited Expanded Gate 1 for new routes.

Therefore they should **not** yet be treated as final combined eligibility counts.

## Why keep this as a draft

The old canonical universe remains useful as a stable snapshot of the first search phase.

This draft exists so that the second phase can be audited as one coherent set before replacing the canonical files.

Do not promote this file into `opportunities.csv` until:

1. the remaining Expanded Gate-1 conditionals are resolved as far as reasonably possible;
2. old merge/reframe rows have their richer Discovery-2.0 notes folded into the existing records;
3. the Osaka placeholder/new-route provenance is reconciled;
4. `eligibility.csv` is rebuilt from the same 165-record snapshot.

## Current interpretation

The expanded universe is now large enough to test the central thesis rigorously:

> Which Master's programmes make the applicant's cross-layer engineering + healthcare-data background an admissions and career advantage?

The answer should emerge from the gates, not from further broad search.
