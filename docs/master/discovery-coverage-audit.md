# Discovery Phase 2.0 - Coverage and Freeze Audit

## Status

**Discovery is now frozen for broad search.**

This does not mean the final application list is fixed. It means the search space is now broad enough that new generic web searches are producing mostly variants of programme architectures already represented.

The current staging universe contains **95 records**.

Merge audit:

| Action | Count |
| --- | ---: |
| Genuinely new opportunity | 86 |
| New concrete route replacing a placeholder | 1 |
| Exact duplicate of an existing canonical degree | 5 |
| Reframing/subtrack of an existing canonical degree | 3 |
| **Total staging records** | **95** |

The 87 genuinely new/replacement routes have now been promoted after Gate 1. Together with the original 78 records, the canonical universe contains **165 application-distinct routes**.

## What the discovery phase now covers

The search is no longer anchored to BCI, genetics, or generic CS.

It covers the programme architectures most likely to amplify the applicant's cross-layer profile:

1. Computational Bioengineering
2. Engineering-major Bioinformatics
3. Bioinformatic / Biological Information Engineering
4. Biomedical / Health Data Science
5. Medical / Biomedical Informatics
6. Quantitative / Systems Biology for quantitative entrants
7. Broad Biomedical Engineering with computational/data tracks
8. Systems / Information Engineering applied to living systems
9. CS/Data thesis degrees with serious biological research ecosystems
10. Structurally funded research Master's degrees with cross-modality biomedical labs
11. Australia 2028 routes compatible with a return-to-Vietnam strategy

## Cross-modality coverage

The expanded search now contains programmes capable of using all three prior healthcare-data modalities:

```text
Earable      -> physiological / neural signals
VinBigData   -> medical imaging
GeneStory    -> genomic / sequencing data
```

and programmes where these are treated as instances of a broader problem:

```text
measurement / raw biological evidence
-> representation / QC
-> pipeline / computation
-> modelling / inference
-> validation
-> usable scientific / clinical / product output
```

## Why search should stop here

The last search waves increasingly returned one of the already-known structures:

- another BME with signal/imaging/informatics tracks;
- another bioinformatics programme with computational methods;
- another health-data programme;
- another CS thesis route with a computational-biology lab.

Continuing broad discovery would increase maintenance and Gate-1 workload without materially increasing option diversity.

New opportunities can still be added later when triggered by:

- a named scholarship;
- a specific PI/lab;
- a new 2028 programme;
- a programme architecture genuinely absent from the current universe.

## Data-quality caveat

Discovery completeness is **not** evidence that all programmes are eligible or affordable.

Many staging rows deliberately preserve unresolved questions in:

- formal prerequisite-credit mapping;
- foreign-degree equivalence;
- language of instruction;
- 2028 cycle publication;
- supervisor availability;
- funding amount / renewal / international eligibility.

Those uncertainties now belong to the gates, not to further discovery.

```text
      |
      v
Gate 3 - Profile Differentiation
      |
      v
Gate 4 - PI / research environment
      |
      v

```

The key new gate is **Profile Differentiation**:

> Does this programme amplify Mechatronics + systems + signals + imaging + genomics + software into a coherent Research Engineer identity, or flatten the applicant into a weaker conventional CS/Bio/EE profile?

No shortlist should be created before the expanded universe has passed at least Gate 1 and Gate 2.
