# Primary PI Outreach Briefs - 2027 Research Master's

This document converts the supervisor-fit audit into seven concrete outreach hypotheses.

The purpose is not to write generic emails. Each brief identifies:
- what the lab is actually working on now;
- what evidence from the applicant is relevant;
- one plausible research question;
- what not to overclaim;
- whether outreach should happen now.

## 1. HKUST ECE - Yiwen Wang

Her current profile lists an in-press work on **quantized kernel reinforcement learning for brain-machine interfaces**, alongside prior work on scalp-EEG noise suppression and neural-state estimation.

# Reusable research themes

The seven primary PIs can be covered with three reusable proposal kernels rather than seven unrelated ideas.

## Kernel A - Robust adaptive neurophysiological inference

Best for:
- Yiwen Wang
- Raymond Tong
- partly Chul Kim

Core problem:

> physiological/neural signals are non-stationary, artifact-prone and person-specific; build adaptive and uncertainty-aware inference that remains useful in closed-loop systems.

## Kernel B - Measurement-aware wearable / neural systems

Best for:
- Chul Kim
- Sunwoo Lee
- Shiming Zhang
- Ghim Wei Ho

Core problem:

> co-design sensors, acquisition hardware and inference instead of treating signal processing as a repair layer after poor measurement.

This maps closely to the applicant's current scientific-software principle of preserving measured evidence before interpretation.

## Kernel C - Closed-loop biomedical control

Best for:
- Sungmin Park
- Raymond Tong
- Chul Kim

Core problem:

> estimate physiological/neural state from imperfect evidence and use it to adapt an intervention, stimulation or assistive device safely.

This kernel makes the undergraduate automatic-control background genuinely relevant rather than decorative.
