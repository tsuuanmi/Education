# Programme Fit Specification

## Core idea

A Master's is a strong fit when it does **not** merely add another domain to an already broad profile.

It should identify and deepen the methodological layer that is common across the applicant's previous work:

```text
physical / biological system
        ->
measurement / acquisition
        ->
raw biological evidence
        ->
signal / image / sequence processing
        ->
representation / modelling
        ->
algorithms / software / pipelines
        ->
scientific inference
        ->
biological / clinical knowledge
```

The applicant has already worked at several points in this stack:

- Mechatronics -> systems, hardware, sensors, control;
- Earable -> physiological / neural signals;
- VinBigData -> medical imaging;
- GeneStory -> genomic / sequencing data;
- DNA -> scientific software, pipelines and reproducibility.

The Master's should therefore create **vertical methodological depth from existing horizontal breadth**.

## Depth-over-domain principle

Do not optimize for adding a fifth biological domain.

Prefer programmes that deepen:

- probability and statistics;
- scientific inference;
- modelling;
- algorithms and data structures;
- scientific computing;
- optimization;
- machine learning with rigorous validation;
- reproducible workflows and systems;
- research methodology.

Biological domains should be application spaces for these transferable methods.

## Engineering-rooted identity

The applicant's home identity should remain engineering / systems-oriented.

The desired transformation is:

```text
Systems / Mechatronics Engineer
        ->
Biological information / healthcare systems
        ->
Quantitative modelling + scientific computing
        ->
Research Engineer for Biological Systems
```

Avoid programmes that require the applicant to discard the engineering identity and restart as a weaker pure-CS or pure-biology applicant.

## Missing biology should be teachable

A strong-fit programme treats missing biology as curriculum rather than as proof that the prior profile is wrong.

Prefer conversion architectures where:

- Engineering is an accepted starting identity;
- biology / physiology / molecular foundations are added inside the degree;
- professional biological-data experience is valued;
- thesis work then integrates the domains.

Hard prerequisite-heavy programmes can still be excellent academically, but they are less naturally designed for this trajectory.

## Transferable methods matter more than modality count

The ideal programme does not need to cover EEG + imaging + genomics simultaneously.

Cross-modality breadth is useful mainly as evidence that the programme teaches a reusable abstraction layer.

A single-domain research project can still be excellent when it develops transferable methods such as:

- probabilistic modelling;
- statistical inference;
- scientific programming;
- scalable computation / HPC;
- data systems and workflows;
- reproducibility;
- algorithm design;
- validated machine learning.

## Research ownership

Because the applicant already has industry R&D experience, coursework alone has lower marginal value.

A strong Master's should provide extended ownership of an open-ended problem:

```text
problem formulation
-> literature
-> method design
-> implementation
-> experiments
-> failure / iteration
-> analysis
-> scientific claim
-> thesis / publication / software
```

Substantial thesis or PI-driven research is therefore strongly preferred.

## Identity compression

A successful Master's should make the applicant easier to explain.

Before:

> Mechatronics -> EEG -> medical imaging -> genomics -> scientific software.

After:

> A Research Engineer who develops computational methods and systems for biological and healthcare data.

Previous experiences should become evidence for one trajectory rather than separate stories.

## Option-value guardrail

Do not over-specialize prematurely.

The preferred long-term identity is:

```text
Biological Systems Research Engineer
          |
   -----------------
   |       |       |
 signals  imaging  omics
```

A domain-specialized Master's is acceptable when the specialization is primarily methodological and the learned methods remain portable.

## Degree-title agnostic

Potential degree labels include:

- Biomedical Engineering;
- Bioengineering;
- Biological Information Engineering;
- Computational Biology;
- Bioinformatics;
- Systems Biology;
- Electrical / Computer Engineering;
- Computer Science / Data Science research degrees.

Programme title is weak evidence.

Stronger evidence is:

- curriculum;
- PI / lab;
- thesis structure;
- methodological rigor;
- research environment;
- funding;
- career option value.

## Fit vs feasibility

Never collapse all dimensions into one score.

Evaluate separately:

| Dimension | Question |
| --- | --- |
| Formal eligibility | Can the applicant satisfy the published requirements? |
| Profile amplification | Does the existing profile become an advantage? |
| Methods depth | Does the degree add rigorous missing foundations? |
| Research depth | Will it materially develop Research Engineer capability? |
| PI / lab fit | Is there a concrete research environment where this can happen? |
| Option value | Are the methods portable across future biological modalities? |
| Funding | Is the route financially rational? |
| Execution | Are timing, language and tests practical? |

## Canonical fit statement

> An engineering-rooted, research-intensive Master's that uses quantitative and computational methods to study biological or healthcare systems; accepts interdisciplinary engineering entrants as a feature rather than a deficiency; teaches missing biological foundations; develops rigorous statistics, modelling, algorithms and scientific computing; supports substantial thesis research; and preserves enough methodological breadth to move among signals, imaging, omics and future biological-data types.

Short form:

> **Engineering as the foundation. Biological systems as the application domain. Computation and modelling as the transferable core. Research as the mode of learning.**
